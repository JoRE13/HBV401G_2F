\section*{1. Scope}
This document presents the implemented test fixture and mock objects for one controller component in our system.

Controller under test:
\begin{itemize}
    \item \texttt{FlightController}
\end{itemize}

Methods covered by the fixture:
\begin{description}[leftmargin=2.5em]
    \item[\texttt{searchFlights}] \nolinkurl{(String departureCode, String arrivalCode, ZonedDateTime date)}
    \item[\texttt{filterByDepartureTimeRange}] \nolinkurl{(List<Flight> inputFlights, ZonedDateTime start, ZonedDateTime end)}
\end{description}

\section*{2. Test Fixture (JUnit)}
The test fixture is implemented in \texttt{src/test/java/airline/controllers/FlightControllerTests.java}.

It provides:
\begin{itemize}
    \item clean setup with \texttt{@BeforeEach}
    \item clean teardown with \texttt{@AfterEach}
    \item injection of a mock storage dependency into the controller under test
    \item deterministic fixture data for repeatable tests
\end{itemize}

Example fixture setup:
\begin{lstlisting}[language=Java,caption={Fixture setup and teardown (excerpt)}]
@BeforeEach
void setup() {
    mockFlightRepository = new MockFlightRepository();
    controller = new FlightController(mockFlightRepository);
    ...
    // test data objects created here (f1, f2, f3, f4)
}

@AfterEach
void cleanup() {
    controller = null;
    mockFlightRepository = null;
    ...
}
\end{lstlisting}

\section*{4. Mock Objects and Simulated Behavior}
Primary mock:
\begin{itemize}
    \item \texttt{MockFlightRepository}
\end{itemize}

Simulated behavior:
\begin{itemize}
    \item returns preconfigured search results for \texttt{findByRouteAndDate}
    \item does not implement real repository/database search logic
    \item keeps unrelated interface methods unsupported to remain minimal
\end{itemize}

Bonus mock with different behavior:
\begin{itemize}
    \item \texttt{EmptyFlightRepositoryMock}
\end{itemize}

Simulated behavior:
\begin{itemize}
    \item always behaves as empty storage
    \item enables testing controller behavior under ``no data available'' conditions
\end{itemize}
